Демонстрационные фотографии и видео приложения.

Как заменить:
1. Проще всего — положить свои файлы с ТЕМИ ЖЕ именами (например,
   7ec84758-6b3c-49d7-805a-67e38d013d03.jpg). JSON менять не нужно.
2. Либо положить файлы с новыми именами и обновить пути в
   assets/data/family_ru.json, family_be.json, family_uk.json, family_en.json:
   поля familyPhoto, members[].photo, members[].birthdayMedia[].source,
   members[].gallery[].media[].source, timelineEvents[].photo,
   timelineEvents[].media[].source, mediaLibrary[].source.
   Путь указывается как /photos/имя-файла.jpg
3. После замены нужен полный перезапуск приложения (ассеты вшиваются в сборку),
   а если в приложении уже сохранялись правки — Настройки → Общие настройки →
   «Перезагрузить данные», иначе покажется сохранённая копия из Hive.

Требования: JPEG/PNG/MP4, имена в нижнем регистре без пробелов, файлы
желательно сжимать (длинная сторона ~1600 px) — они попадают в сборку приложения.
Регистр имён важен для web и Linux.
